3. Where Real Captures Beat AI

Authenticity Principle

AI-generated headshots carry noticeable artifacts, and AI-generated app UIs create illegible fake text and impossible button placement. Real screenshots of working code demonstrate that software is built, deployed, and fully operational—offering true technical proof.

4. Rejection Log (Discernment Criteria)

❌ Rejected Image: Glowing 3D Neon Cloud Matrix

Context: A high-contrast neon graphics rendering generated as a card image for the Weather API project.

Why it was rejected: It looked like generic stock filler. Glowing neon graphics communicate "decorative noise" rather than actual code quality. Replacing it with a real screenshot of the telemetry data chart grounds the portfolio in authentic technical work.

5. Two-Line Style & Consistency Note

Consistency Rule: Real work captures are framed in sharp 16:9 containers with a 1px #E5E7EB border; generated assets are restricted strictly to background textures and icon sets using the #1F2937 slate and #4B7B6E sage palette.

Mood: Grounded, authentic, and deliberate—letting real functional output speak louder than generated aesthetics.
